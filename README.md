# 🚗 Road Accident Analysis – Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Road Accident Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes road accident and casualty data to identify patterns based on accident severity, vehicle type, road type, urban/rural area, light conditions, weather conditions, and road surface conditions.

The dashboard uses **DAX measures, data modeling, calculated groups, interactive slicers, and multiple Power BI visualizations** to provide a clear overview of road accident performance and year-over-year casualty trends.

---

## 🎯 Project Objectives

* Analyze the total number of road accidents and casualties.
* Compare **Current Year (CY)** performance with **Previous Year (PY)**.
* Analyze casualties based on accident severity.
* Identify casualty patterns across different vehicle types.
* Compare casualties between urban and rural areas.
* Analyze the effect of light conditions on casualties.
* Analyze casualties by road type.
* Understand the relationship between vehicle type and light conditions.
* Allow users to interact with the dashboard using filters.

## 🗂️ Data Model

The Power BI model contains two main tables:

### 1. Data

The main accident dataset containing fields related to:

* Number of casualties
* Accident severity
* Vehicle type
* Road type
* Urban/Rural area
* Light conditions
* Weather conditions
* Road surface conditions
* Accident-related attributes

### 2. Calendar

A dedicated calendar table used for:

* Date analysis
* Month-wise analysis
* Year-wise analysis
* Current Year vs Previous Year comparison
* Time-based visualizations

The **Data** and **Calendar** tables are used together for time-based analysis.

---

## 📌 Key DAX Measures

The dashboard uses measures including:

* **CY Casualties** – Calculates current-year casualties.
* **YOY Casualties** – Calculates year-over-year casualty performance.
* **CY Accidents Count** – Calculates current-year accident count.
* **YOY Accidents** – Calculates year-over-year accident performance.

Additional filtering is applied to the casualty measures to analyze:

* Fatal casualties
* Serious casualties
* Slight casualties

---

## 📈 Dashboard KPIs

The dashboard contains KPI cards for:

### Total CY Casualties

Displays the total number of casualties for the current year.

### Total CY Accidents

Displays the total number of accidents for the current year.

### CY Fatal Casualties

Shows casualties classified as **Fatal**.

### CY Serious Casualties

Shows casualties classified as **Serious**.

### CY Slight Casualties

Shows casualties classified as **Slight**.

The dashboard also displays corresponding **YOY values** for comparison.
